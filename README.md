# Tela de carregamento

Projeto de estudo de uma tela de carregamento com barra de progresso animada em JavaScript.

🔗 **Demo:** https://matheusdiamantino.github.io/Tela-de-carregamento/

![Imagem de fundo](img/bg.png)

## O que foi praticado

- Barra de progresso controlada com `setInterval`
- Redirecionamento ao chegar em 100%
- Bloqueio do menu de contexto e dos atalhos F12 e Ctrl+Shift+I
- HTML e CSS para o layout

## Como abrir

Abra o `index.html` no navegador. Para mudar o destino, troque `window.location.href` no `script.js`.
